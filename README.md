# Curso de Maturidade no Espírito

Landing page em Next.js, preparada para hospedagem Node.js padrão, incluindo o
Web App da Hostinger.

## Requisitos

- Node.js 20.9 ou superior
- npm

## Desenvolvimento local

```bash
npm install
npm run dev
```

O site ficará disponível em `http://localhost:3000`.

## Build de produção

```bash
npm install
npm run build
npm start
```

## Configuração na Hostinger

- Framework: Next.js
- Versão do Node.js: 20 ou superior
- Diretório raiz: raiz deste repositório
- Comando de instalação: `npm install`
- Comando de build: `npm run build`
- Comando de inicialização: `npm start`

O projeto não utiliza banco de dados, armazenamento de objetos ou variáveis de
ambiente. As imagens e os vídeos necessários estão versionados em `public/`.
